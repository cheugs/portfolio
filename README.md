# Portfolio · Marie Louise Chengho Fongang

My personal portfolio: who I am, my journey, and my projects in full-stack development,
data engineering, data science, data analysis and AI engineering.

**Live site:** https://cheugs.github.io/portfolio/

**Author:** Chengho Fongang Marie Louise

## What is inside

- Five "worlds", one per role, each with what I can do, my tools, my projects and my experience
- A detailed sheet for every project and experience: what it is, what I did, the tools, the results
- An interactive skills map
- A contact form
- French and English versions

## Built with

Vite, Three.js (3D objects), GSAP (animations), plain HTML, CSS and JavaScript.

## Run it locally

Requirements: Node.js 20 or later.

```bash
npm install
npm run dev
```

| Command | What it does |
|---|---|
| `npm run dev` | Starts the site locally |
| `npm run build` | Builds the production version into `dist/` |

## Where to change things

| File | Contains |
|---|---|
| `src/content.js` | All the text, in French and English: sections, timeline, projects, worlds, links |
| `src/details.js` | The detailed sheet of each project and experience |
| `src/scene.js` | The 3D objects in the background |
| `src/main.js` | Animations, navigation, worlds, skills map, contact form |
| `src/style.css`, `src/universe.css`, `src/clay.css` | Styles |

The site is deployed to GitHub Pages automatically on every push to `main`.
